# 个人 IP：绿衬衫青年

## 形象依据

唯一默认角色基准图为 `assets/character/green-youth-reference.png`（相对于 Skill 根目录）。它是用户比较后交由助手按正文配图适配度选择的新版简化造型。生成前先查看此图；支持图像参考输入时将它作为角色参考传入。参考图约束角色外形与配色，不约束站姿、视角、咖啡杯和画面构图。若工具无法传入参考图，使用本文件的文字定义，不宣称已使用图像参考。

角色暂用描述性称呼“绿衬衫青年”，并非用户已确定的名字。它代表用户的个人视觉形象，不是对真实相貌的写实还原。

## 固定识别特征

- 年轻成年男性，大学毕业前后的青年感；自然、专注、好奇，有行动力和克制的幽默感。
- 黑色微乱短发，顶部一小撮弯曲翘发；不变成长发，不增加帽子或眼镜。
- 简化的小黑眼睛、短鼻线、小嘴；头略大于写实比例，四肢轻巧但保持成年人的比例。以基准图为准，不画成幼儿或大头 Q 版。
- 灰调玉绿/青绿色宽松衬衫，敞开穿、袖口随意挽起；纯白无图案 T 恤；炭黑色膝上休闲短裤；白色运动袜；米白运动鞋带少量浅暖黄点缀。
- 角色色块以绿色、白色和炭黑为主，皮肤自然浅暖色；不让鞋子、道具全部跟衣服同绿。
- 不添加水纹、字母、品牌标识或胸前徽章。默认不戴耳机；用户明确要求时可加，颜色与衣服区分。

## 可变项与动作

姿态、视角和表情随正文变化，可以观察、思考、困惑、尝试、推拉、搬运、分拣、搭建、修补、记录；站姿不固定为插兜或交叉腿。需要多人物时可使用同一 IP 的多个实例，但保持外形一致。

咖啡杯是可选日常道具：需要时使用暖陶色杯身、白色杯盖，与绿衬衫形成柔和对比。动作需要双手时不拿杯；不得为了保留咖啡杯而让角色只站在角落。笔、本子、耳机均不是固定配件。

角色应当承担核心概念动作。允许环境、机器和比例关系荒诞，但保持人形、短发和服装识别特征；不要像旧小黑一样变成漏斗、黑洞、黑盒或机器零件。可以让他操作、修补或推动这些物件。

## 绘制边界

采用简练黑色手绘轮廓和少量平涂色。缩小到正文尺寸仍能认出发型、绿衬衫、黑短裤即可。衣褶、发丝、鞋带与五官进一步概括，不照搬基准图中的全部细节。机制类正文图可把角色画小，以发型轮廓和服装配色识别；基准图不是人物必须占据的画面比例。不画成精细日漫帅哥、时装写真、写实肖像、商业吉祥物或儿童卡通。亲近、轻快的青年感可以保留，不沿用旧角色“空表情、全黑、不能微笑”的要求。
