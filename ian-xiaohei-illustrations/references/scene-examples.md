# 个人 IP 多场景样片

这六张图用内置 image_gen 实际生成，并逐张查看。每次仅传入同一张角色基准图；每张独立生成，其中第六张本身是一幅连续小漫画。覆盖八类构图，但只代表首轮样本，不保证任意复杂场景都稳定。

## 使用方法

角色身份始终以 `assets/character/green-youth-reference.png` 为准。以下图片只校准动作参与、线条密度、色彩与留白，不是固定模板；正常任务不必一次读取全部样片。按需查看最相关的一张，机制类优先第 07 张的主次与简练程度，其他动作可参考第 02、04 张；支持多图参考时，先传角色基准图，再将选中的一张明确标为“场景风格参考，不复制构图”。

不要从样片改变发型和服装，不把跪姿、咖啡杯或旧物件变成新的默认设定。当前文章必须重新发明隐喻。旧小黑 `assets/examples/` 仍是历史材料，不与本组混用。

## 逐图观察与边界

- **较量的共同代价（优化版）**：对比后新增的一张，不计入首轮六张。人物更小，三箱货物、连续绳索、一处裂缝及脚与板的接触关系更清楚；人物仍有少量鞋面和脸颊细节。优先用于机制类画面主次校准，不能作为所有主题的固定站姿或比例。该图使用两张参考（个人 IP 身份与小黑对比图的线条/构图），不是严格单变量测试。生成记录见仓库 `examples/refinement-generation.json`。小黑对比图在仓库 `examples/comparison/`，不属于当前默认角色素材。

- **修补信息断点**：可用；管道灰色填充和鞋面细节偏多，仅校准动作，不作为线条简练度的首选。
- **按用途筛选**：首选校准图；角色与场景配色区分清楚。桌面和鞋带仍可更概括。
- **从忙乱到理顺**：可用；线团部分较密，后续同类图应控制线圈数量。
- **把方法搭起来**：首选校准图；道具概括、配色克制；仍需按新正文另创隐喻。
- **边走边调整**：可用；验证可选咖啡杯与绿色区分。纸路与橙线是同一学习路径的两种表达，不照搬双路径布局。
- **试一下再修改**：可用；角色在三状态中可辨识，但小车轮子与工具细节略有变化，复杂物件连续性仍需逐格核对。

共同结果：这六张中黑短发、翘发、玉绿衬衫、白 T、黑短裤、白袜与浅色运动鞋具有较一致的辨识度；可换跪姿、侧背视角、坐姿和表情；咖啡杯仅在路线图中使用。已目视核对本组中文标注，未发现明显错字；这不是对未来图片的可读性保证。

仍需改进：有些五官和鞋带偏精细，少量皮肤及衣服阴影没有完全省略；新 prompt 应明确用平涂、减少装饰细节，复杂连续物件优先保持形状一致。留白做了目视检查，未进行像素分割测量。

完整生成提示词记录在仓库根目录的 `examples/personal-ip-generation.json`；图像尺寸、哈希和逐图检查记录在 `examples/personal-ip-review.json`。安装版只带此索引与图片，生成记录在仓库中维护。
